Prompt Library

Real prompts from Urology faculty, lightly generalized. Copy one, swap in your details in [brackets], and go.

How to use these. Every prompt here follows the same pattern: what you want, the facts, a draft to review, and an invitation to ask questions. PHI-tagged prompts involve patient data — use them only in a Michigan Medicine–approved tool: U-M GPT with the GPT-4.1 or GPT-5.6 Sol model selected, or Codex (U-M GPT Toolkit). Maizey and the Claude/Llama models inside U-M GPT are not PHI-approved. Everything else works in any chatbot.

The universal closer

Add this to the end of anything

The single most useful sentence: it makes the model surface ambiguity before doing an hour of work in the wrong direction.

Ask me any questions you have before you get started.

Administrative

Dress up a plain email

The neighborhood-well email. Same words in, formatted out — five minutes.

I'm sending an email to [audience] about [topic]. I want a nicely formatted email similar to [a previous email or style you like — attach or describe it]. Keep my wording; add structure, a short header, and a clearly set-off box for the key dates or actions. Here is the draft:

[paste your plain-text draft]

Letter of recommendation in my voice

Give it two or three of your past letters so it writes like you, not like a template.

Draft a letter of recommendation for [name], applying to [program / position]. Write in my voice — here are two letters I've written before for reference: [attach or paste]. Key points to include: [3–5 bullets: role, accomplishments, specific anecdotes, comparison to peers]. Target length one page. Make a draft for me to review, and ask me any questions you have before you start.

Turn an outline into slides

Base slides from a description, using a template you already have.

Turn this outline into a first-draft slide deck: [paste outline or describe the talk, audience, and length]. Use the attached template's style [attach .pptx]. One idea per slide, minimal text, speaker notes with the talk track for each slide. I'll edit from your draft — don't over-polish. Ask me any questions before you start.

Sell things / handle a multi-step chore end to end

The Facebook Marketplace prompt, generalized: give the list, your rules, and who decides.

I need to [goal, e.g., sell these items / schedule these meetings / reconcile these records]. Here are the items and details: [list]. My priorities: [e.g., speed over price / minimize my time]. You'll ask me before any final decision, but otherwise run the process. Tell me your plan before you get started, and ask me any questions you have.

Clinical PHI — approved tools only

Patient education handout PHI

Plain-language, reading-level controlled, in the format your clinic uses.

Write a one-page patient education handout on [condition / procedure] for [adult / pediatric] urology patients at a 6th–8th grade reading level. Cover what it is, what to expect, warning signs to call about, and when to follow up. Neutral, reassuring tone; short paragraphs and headers. Do not include any identifying patient information. Draft for my review.

Summarize outside records for a new patient PHI

The department's #1 wished-for use. Works today in U-M GPT (GPT-4.1 or GPT-5.6 Sol) with pasted text or uploaded documents.

These are outside records for a new [oncology / stone / etc.] patient: [paste or attach]. Build a chronological summary: presenting problem and first diagnosis; treatments completed with dates; relevant imaging and pathology with key findings; current medications; open questions the records don't answer. Flag anything that looks inconsistent between documents. Be concise — this is my pre-visit chart prep.

Draft a reply to a patient message PHI

You review and send; it drafts.

Draft a reply to this patient message: [paste]. Context: [relevant plan / recent visit / result]. Warm, plain language, under 120 words, no medical jargon, and end with what the patient should do next and when. I will review before sending.

Prior authorization / appeal letter

Give it the denial language and the guideline; it structures the argument.

Write a prior-authorization appeal for [medication / procedure]. Denial reason: [paste]. Clinical justification: [bullets — diagnosis, failed alternatives, guideline support]. Cite the relevant guideline ([AUA / NCCN / etc.]) accurately — if you are not certain of a citation, say so rather than inventing one. Formal tone, one page. Placeholders for patient identifiers.

Research & writing

Edit my draft in my own voice

Assist-mode, which 58% of us already use: your words, tightened.

Edit this [abstract / section / grant aim] for clarity and concision without changing my voice or my claims. Keep my terminology. Flag any sentence where the logic is unclear rather than silently rewriting it. Show changes as a marked-up version plus a clean version. [paste text]

Literature summary with verifiable sources

Built around the verification habit: sources you can actually open.

Summarize the current evidence on [question] for a [grant background / manuscript introduction / journal club]. For every claim, give the citation with DOI or PMID. Only cite papers you are confident exist; if unsure, say "verify" next to it. End with the 3 papers I should read in full and why.

Check my statistical code

Refining beats generating from scratch — you stay the analyst.

Review this [R / Stata / Python] code for a [describe analysis, e.g., mixed-effects model of X on Y]: [paste]. Check for errors in logic, model specification, and variable handling. Explain each issue and suggest the fix, but do not rewrite the whole script. Then list the assumptions I should verify before trusting the output.

Reformat a biosketch to a new template

The retreat build-along: current document + new rules → converted document.

Here is my current biosketch: [attach]. Here are the instructions for the new required format: [attach or paste]. Convert my biosketch to the new format. Keep every accomplishment and citation exactly as written; only restructure. Tell me anything the new format asks for that my current biosketch doesn't contain, so I can supply it.

Have Chat write the Claude Code prompt

For anything bigger than one ask. Four sentences in, five pages out.

I want Claude Code to [goal — manage a project, build a tool, process a set of files], including [scope]. I'll be using [tools / accounts / files it can access]. Create the prompt I should paste into Claude Code to start this project: operating rules (ask before any consequential action), file structure, standards, and a phased plan. Ask me any questions you have before drafting the prompt.

Handoff to a new session

When a long chat has all the decisions in it and you need to move the work elsewhere.

Produce a handoff document for a new Claude Code session with all the key decisions from this project: context, the authoritative rules or formulas, data sources and their quirks, what was built, what verification we did, and what's still pending. Write it so someone with no memory of this chat could continue the work.

Everyday

Fix a thing from a photo

Thermostat errors, dashboard lights, settings screens — take a picture and ask.

[attach photo] I'm getting this on my [device]. What do I do to fix it? Give me the two or three most likely causes in order, with the exact steps for each.

Explain a concept at my level

"Predictive vs. prognostic" — say who you are, get the right depth.

Explain [concept] to me in the context of [your field / the situation]. I'm a [urologist / statistician / etc.] — skip the basics I'd already know and focus on where the distinction actually matters in practice. One good example.

Your first thirty minutes

If you've never used one of these tools, start here.

I'm a [role] and I've never really used you before. Ask me five questions about my week, then suggest three specific things you could take off my plate — with the exact prompt I'd use for each.
